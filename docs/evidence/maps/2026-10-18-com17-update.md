`7db5be42531de7622422ff2c5b557e2cddf8c2125f904fac197db85f7cf464aa`.
The extracted application's image checksum and validation hash are valid.

Private recovery directory, relative to the worktree:
`.local/maps/com17-recovery/20261018-092257/`.
It contains `full-flash-before.bin`, extracted app/boot/table/NVS/PHY/coredump,
hash manifest, installation plan/result, original world-region bytes and

without source-commit attribution. NVS and crash data are private; do not publish
the snapshot. Ordinary firmware rollback restores app/table while retaining
later NVS and SD data; whole-flash rollback also rewinds NVS and requires a
separate deliberate decision. No rollback was executed.

## Open gates / next milestone

Final sampled DMA free is 3,827 bytes, largest block 3,328; PSRAM free
22,215,148. The bridge is off, unpaired, with no recorded failure. These DMA
values are below the new Pair admission thresholds before reclamation, so the
COM39 memory result must not be generalized to COM17. Further memory/pairing
qualification on this device is required; no complete pairing was claimed.
Map UI/legacy compatibility, active-radio profiling and sustained regression
acceptance are not proven by this firmware installation.

COM39 remains on ESP-Hosted 1.4.1 by explicit user requirement. COM17's existing
3.0.6 C6 and the OrcDial firmware remain unchanged. The next milestone is the
COM17 memory/pairing check, followed by the outstanding integration gates.
